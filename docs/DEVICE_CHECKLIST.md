# 微信开发者工具与真机验收清单

以下均未在微信平台实测。Node 模拟 API 不能代替这些检查。

- 导入项目根目录、合法 AppID、基础库3.7.0+，实际编译并检查控制台。
- Android/iOS 分别拍照、选JPG、选透明PNG；检查EXIF方向、大像素相片、加载失败。
- 上传自动生成，连续切换52→78→104→120，最终尺寸、豆位数、统计完全一致。
- 原图含半透明毛发、问号、文字、爪印时完整适配，无裁剪、黑边、透明RGB污染。
- 固定小狗原图生成内部100及全部正式尺寸，对齐成熟软件豆位，检查蓝灰双眼/高光、灰粉灰棕鼻头、毛发/背景、装饰；记录缺陷并调优。
- 真实人物/动物照片测试自动/照片/抖动模式，明暗层次和杂色可接受。
- 替换真实品牌色卡，核对实物、色值来源、图纸色号和数量。
- 双指缩放和拖动预览，确认Canvas不截断、不改变图纸数据。
- 52带号单张、78/104四分区、120九分区、无字图均能导出，低内存Android和iOS也能完成。
- 放大检查完整色号、字色、棕色边框、坐标首尾、100/110/120三位数间距、分区延续、标签无溢出。
- 区边界无重复遗漏，分区统计相加等于全图；区内图例为本区用量，页面为全图用量。
- 相册首次允许/拒绝/永久拒绝打开设置/批量中途失败，确认已保存数及重试行为。
- 微信后台配置隐私协议，检查首次相机、相册、保存授权。
- 开发者工具与两平台PNG和桌面核心输出对齐；色彩管理差异记录版本和色值后排查。
